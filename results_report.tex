\begin{abstract}
This report presents a comprehensive analysis of Microsoft (MSFT) stock forecasting using multiple time series methods across different timeframes and experimental configurations. The study compares five forecasting methods—ARIMA, Chronos Base, FM (Foundation Model), Naive, and Sundial—across daily (1d) and hourly (1h) data frequencies. Three experimental setups were employed: train-less-year-linear, train-less-year-log, and train-restricted-years. Performance was evaluated using standard metrics including MSE, MAE, RMSE, and MAPE across various training periods and prediction horizons.
\end{abstract}

\section{Introduction}

\subsection{Timeframes}
The analysis encompasses two primary data frequencies:
\begin{itemize}
\item \textbf{Daily (1d)}: End-of-day closing prices for long-term trend analysis
\item \textbf{Hourly (1h)}: Intraday price movements for short-term forecasting
\end{itemize}

\subsection{Experimental Configurations}
Three distinct training approaches were implemented:
\begin{itemize}
\item \textbf{train-less-year-linear}: Linear scaling with training periods under one year
\item \textbf{train-less-year-log}: Logarithmic scaling with training periods under one year
\item \textbf{train-restricted-years}: Training restricted to specific year ranges
\end{itemize}

\subsection{Forecasting Methods}
\begin{itemize}
\item \textbf{ARIMA}: AutoRegressive Integrated Moving Average, a classical statistical method
\item \textbf{Chronos Base}: Pre-trained time series foundation model from Amazon
\item \textbf{FM}: Foundation Model approach for time series forecasting
\item \textbf{Naive}: Simple baseline using last observed value
\item \textbf{Sundial}: Specialized time series forecasting model
\end{itemize}

\subsection{Evaluation Metrics}
Performance was assessed using:
\begin{itemize}
\item \textbf{MSE}: Mean Squared Error
\item \textbf{MAE}: Mean Absolute Error
\item \textbf{RMSE}: Root Mean Squared Error
\item \textbf{MAPE}: Mean Absolute Percentage Error
\end{itemize}

\section{Comparative Analysis}

\subsection{Method Performance Comparison}

\subsubsection{Daily Forecasting}
Across all daily forecasting experiments, several patterns emerge:
\begin{itemize}
\item ARIMA and Naive methods achieve the lowest MAPE values (around 1.22\%)
\item Foundation models (Chronos, FM, Sundial) show consistent but slightly higher error rates
\item Training period length has varying impact across methods
\end{itemize}

\subsubsection{Hourly Forecasting}
The hourly timeframe presents different characteristics:
\begin{itemize}
\item All methods face increased difficulty with shorter-term predictions
\item Performance variance increases compared to daily forecasts
\item Model rankings may differ from daily results
\end{itemize}

\subsection{Training Configuration Impact}

\subsubsection{Linear vs Logarithmic Scaling}
Comparing the two sub-year training approaches:
\begin{itemize}
\item Linear scaling provides more uniform coverage of training durations
\item Logarithmic scaling focuses on early training period differences
\item Both reveal similar overall performance patterns
\end{itemize}

\subsubsection{Restricted Years}
The multi-year training experiments show:
\begin{itemize}
\item Extended training data benefits vary by method
\item Some models plateau in performance after certain durations
\item Traditional methods may be more data-efficient
\end{itemize}

\section{Conclusions and Recommendations}

\subsection{Key Findings}
\begin{itemize}
\item Traditional methods (ARIMA, Naive) remain competitive for stock price forecasting
\item Foundation models offer consistency but not necessarily superior accuracy
\item Training data quantity shows diminishing returns beyond certain thresholds
\item Hourly forecasting is substantially more challenging than daily
\item No single method dominates across all configurations and horizons
\end{itemize}

\subsection{Practical Recommendations}
\begin{itemize}
\item For production systems, consider ensemble approaches combining multiple methods
\item Match training duration to available computational resources
\item Naive baselines should always be included for comparison
\item Daily forecasting is more reliable than hourly for most applications
\end{itemize}

\subsection{Future Research Directions}
\begin{itemize}
\item Investigate hybrid models combining traditional and foundation model approaches
\item Explore additional feature engineering and exogenous variables
\item Test on broader range of stocks and market conditions
\item Evaluate ensemble and model averaging strategies
\item Study computational efficiency and deployment considerations
\end{itemize}
